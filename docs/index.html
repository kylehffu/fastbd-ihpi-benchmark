The Scoring Formula

IHPI = (0.30 * CNRR) + (0.40 * TPD_160) + (0.30 * RS_160) - Penalties

- CNRR (Client Name Recovery Rate): Measures whether the client's verified first name was harvested from past feedback (30 pts). Read the full study at https://fast-bd.com/cnrr.
- TPD_160 (Technical Proof Density): Measures frequencies of concrete numbers ($ amounts, latencies, percentages) and platform technologies (40 pts).
- RS_160 (Readability & Structure): Evaluates optimal word count (18-28 words) preventing cognitive overload (30 pts).
- Penalties: Immediate deductions for filler expressions (*"I hope this finds you well"*, *"Dear Hiring Manager"*, *"look no further"*).
